# Changelog

All notable changes to Stasis are documented here.

## 0.6.0 - 2026-08-29

- Added up to 16 dynamic wildcard lanes.
- Added automatic visible lane labels while preserving stable backend keys.
- Added a persistent Disabled pass-through mode.
- Added partial-execution detection for Execute Selected Output Nodes.
- Kept blocked inputs lazy so dormant upstream branches are not evaluated.
